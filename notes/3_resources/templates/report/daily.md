## 🧩 カテゴリ3層構造

### ■ 第1層：目的軸（Why）

管理職業務を目的ベースで俯瞰

| カテゴリ       | 概要                         |
| ---------- | -------------------------- |
| **組織運営**   | 組織を維持・強化する活動（制度、評価、人事、仕組み） |
| **成果創出**   | PJ推進や業務改善など、直接価値を生む活動      |
| **リスク／統制** | 品質・納期・コンプラ・安全などの未然防止や是正対応  |

---

### ■ 第2層：粒度軸（What）

第1層の下に置く“管理単位”

| 上位カテゴリ | 下位カテゴリ（例）                          |
| ------ | ---------------------------------- |
| 組織運営   | メンバー管理／制度設計／採用・育成／会議運営／情報共有        |
| 成果創出   | PJ推進／施策企画／業務改善／資料作成／顧客対応           |
| リスク・統制 | 品質管理／スケジュール管理／コスト管理／トラブル対応／安全・法令対応 |

---

### ■ 第3層：リソース／視点軸（How）

上位カテゴリを“使う資源”や“関与形態”で補助分類

| 軸      | 例               |
| ------ | --------------- |
| **ヒト** | 育成・面談・アサイン・1on1 |
| **モノ** | 設備・ツール・開発環境     |
| **カネ** | 予算・工数・コスト       |
| **情報** | 報告書・データ分析・課題共有  |
